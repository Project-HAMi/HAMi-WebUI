# Icon sources

## GPU

`svg/vgpu-card.svg` is the shared GPU icon for navigation, inventory, resource
summaries, and the fallback when a GPU vendor has no dedicated icon.

- Source: [QingIcon](https://qingicon.com/), by QingCloud, designed by Asorn and Hudie.
- Original: [`duotone/physical/gpu_duotone.svg`](https://github.com/asorn/qingicon-download/blob/525bcc3e7dfe21667332a25b3fe7634d0e90ef2a/duotone/physical/gpu_duotone.svg).
- License: Apache License, Version 2.0, as declared on the official QingIcon site.
  A copy of that license is included in the repository [LICENSE](../../../../LICENSE).
- Local changes: the two fill colors use the existing navigation color variables,
  with the original colors as defaults. The original 48 × 48 viewBox and path
  geometry are unchanged.

GPU compute and memory metrics use their own distinct icons.
